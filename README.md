# restaurant-ai-assistant-

Sobre o projeto

Este projeto consiste no desenvolvimento de um assistente inteligente para restaurantes, utilizando Python.

O objetivo é explorar conceitos de programação, inteligência artificial e integração de sistemas.

Objetivos de aprendizagem

* Praticar lógica de programação com Python.
* Compreender o funcionamento de APIs.
* Conhecer aplicações de inteligência artificial.
* Explorar modelos de linguagem (LLMs).

Tecnologias

* Python
* Git e GitHub
* APIs
* Inteligência Artificial

Status

Projeto em desenvolvime
